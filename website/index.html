A FEW PRACTICAL ANSWERS

Before you launch.

Is AdvisoryOps free to use?

Yes. The public dashboard and browser-based SBOM checker require no account. The code is Apache 2.0 licensed. Optional AI-assisted pipeline runs on your own infrastructure may incur provider charges.

Is this a network scanner?

No. AdvisoryOps brings together public advisory evidence and supports local SBOM component matching. It does not discover devices on your network, inspect traffic, or enforce network controls.

Does a match mean my device is vulnerable?

No. It means the component identity has a candidate relationship to an advisory. Review affected versions, deployment conditions, and manufacturer guidance before deciding on action. A missing match is not proof of safety.

Can I inspect or run the code myself?

Yes. The public repository includes the source, tests, matching-policy documentation, and pipeline instructions. Explore the repository ↗

What does this website track?

This homepage currently has no analytics, advertising pixels, or session recording. Its styles and scripts are served with the page. Launching the app or following an external link takes you to that destination; the linked app documentation describes its separate data handling.
